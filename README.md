# The World in One Day — Tuesday, 24 November 2026

A standard-library-only Python program that draws one 1024x1024 PNG
summarising the world's news of Tuesday 24 November 2026: 13 illustrated
stories with region, source and verification-status chips, a UTC timeline,
a day-in-numbers strip and an also-on band. It embeds subset DejaVu fonts,
parses and rasterises TrueType glyphs itself, and encodes the PNG itself —
no third-party packages, no files read at runtime, no network, deterministic
output.
